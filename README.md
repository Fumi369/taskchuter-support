# Taskchuter Support

Public support and privacy policy pages for Taskchuter for iPhone.
This repository contains only the static website and its app icon, not the
private Flutter application source, signing settings, or task data.

The Japanese support page is `index.html`; the privacy policy is
`privacy/index.html`. GitHub Pages publishes the root of the `main` branch.
All asset and navigation links are relative so the site works at a project URL.

No build process, JavaScript, analytics, external fonts, or contact-form service
is used. The public contact address and operator name are intentionally included
in the pages. GitHub's own hosting data practices are described in the policy.

Update the app-store materials copy in the private app repository when changing
these pages to keep both copies consistent.
